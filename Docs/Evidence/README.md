# Packaged application evidence

These screenshots and JSON reports were captured from the relocated packaged
Windows application, not from the editor viewport. See
[validation details](../VALIDATION.md) for the machine, settings and limits.

Each JSON file is preserved as captured, including its original absolute
`screenshot` path on the test computer. That path records where the evidence
was first written; it is not a file required to run the application. Open the
PNG with the same basename in this folder when viewing the source archive.

Captures retain the in-application OpenStreetMap attribution. The architecture,
terrain and surrounding city remain an artistic public-exterior reconstruction.
